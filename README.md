# 日麻点数计算器（日本麻将点数计算网站）

纯静态网页：直接用浏览器打开即可使用，无需任何服务器或构建步骤。

## 页面
- index.html — 点数计算器主页：自定义手牌 / 副露 / 和了牌 / 荣和或自摸 / 庄位 / 自风与场风 / 宝牌与里宝指示牌 / 赤宝牌 / 附加役勾选，自动分解手牌并给出役种、番数、符数、点数与支付表。
- yaku.html — 役种一览页：全部普通役 + 役满，支持搜索、隐藏役满、只看门清。

## 使用方法（计算器主页）
1. 点击下方牌面按钮把手牌加入手牌区（最多 14 张；暗杠需在杠后多 1 张，共 15 张）。
2. 如需副露，在“副露”区选择吃/碰/明杠/暗杠并输入牌，点击“添加副露”。
3. 选择和了牌（如 8m）、荣和或自摸、庄家、自风/场风。
4. 添加宝牌/里宝指示牌，设置赤宝牌数量，勾选立直/一发/岭上等。
5. 点击“计算点数”，结果区显示役种标签、番数/符数、役满或点数等级、荣和/自摸支付表与符数明细。

## 文件结构
- js/tiles.js — 牌定义与宝牌规则
- js/core.js — 点数引擎：手牌分解、役种判定、符数计算、点数表
- js/app.js — 页面渲染与交互
- css/style.css — 样式
- tests/score.test.js — 引擎测试（30 个用例）：node tests/score.test.js
